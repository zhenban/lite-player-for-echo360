# Echo360 轻量播放器（Lite Player for Echo360）

[![CI](https://github.com/zhenban/lite-player-for-echo360/actions/workflows/ci.yml/badge.svg)](https://github.com/zhenban/lite-player-for-echo360/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/zhenban/lite-player-for-echo360)](https://github.com/zhenban/lite-player-for-echo360/releases/latest)
[![License: GPL v3](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)

**一个用户脚本：用轻快的播放器看 Echo360 课程回放：CPU 占用低得多，两路画面并排，幻灯片章节，PDF 跟着讲课翻页，字幕、笔记等等。**

![播放器：屏幕和摄像机并排，侧栏是幻灯片章节](docs/screenshot.jpg)

> **非官方项目。** 本项目与 Echo360、UNSW 没有任何关系，也未获其认可或支持。提到 “Echo360” 只是为了说明脚本适用于哪个网站。

原播放器播放时会让一个 CPU 核心一直满载，风扇响、耗电。Echo360 轻量播放器用浏览器自带的视频播放器播放同样的视频流，开销接近直接播放视频文件。在 `echo360.net.au`（澳大利亚）上测试过；认不出页面时会自动改用原播放器。

## 安装

1. 安装用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
   Chrome / Edge：在 `chrome://extensions` 打开脚本管理器的“详细信息”，开启 **“允许用户脚本”**（旧版本是开启“开发者模式”）。
2. 安装脚本：从最新版本下载 **[lite-player-for-echo360.user.js](https://github.com/zhenban/lite-player-for-echo360/releases/latest/download/lite-player-for-echo360.user.js)**（脚本管理器会提示安装）。每个版本都附有更新说明。
3. 打开任意一节 Echo360 课程回放，浏览器控制台（F12）会显示 `[Lite Player for Echo360] v… active`。

## 支持的浏览器

- **支持：** 电脑上的 Chrome、Edge、Firefox；安卓上的 Firefox（装 Violentmonkey 或 Tampermonkey）。
- **尽量支持：** iPadOS 和 iOS（iPhone）15.4 及以上的 Safari（装 Stay 或 Userscripts 等脚本管理器）。15.4 是 Echo360 原播放器能运行的最低版本；脚本本身需要 Safari 15。有的管理器会在页面已经启动原播放器之后才运行脚本：这时脚本会接管页面（停下原播放器，从它播到的位置接着播，并防止观看记录被重复上报）。
  - iPhone 上的全屏用系统自带的播放器显示主画面（iPhone 上的 Safari 只允许视频全屏）。iOS 17.1 之前视频由 Safari 自己播放，所以音量均衡和人声增强不可用。
- 太旧的浏览器保留原播放器，并提示原因。

播放器组件下载较慢时（例如网速慢时第一次打开），会显示加载画面和进度，并提供“现在就用原播放器”按钮；20 秒还没加载完会自动打开原播放器。

**设置（⋮）>“存储和诊断”>“复制诊断信息”**（或提示里的按钮）会写明脚本在这个页面是怎么启动的：拦截（在页面的播放器启动前）、接管，或使用原播放器及原因。

## 功能

- **低 CPU 占用**：原生 `<video>` 配合 [hls.js](https://github.com/video-dev/hls.js)，使用硬件解码。
- **双路画面**：屏幕和摄像机可以并排（拖动分割线），也可以画中画（拖动、缩放、吸附四角），或者只显示一路。一键或按 `S` 交换主次，两路保持同步。屏幕长时间没有画面时只显示摄像机（可撤销，可关闭）。
- **画面清晰**：始终使用网络允许的最高画质，屏幕和摄像机可分别设置。
- **字幕与转录**：字幕叠加，四档字号；转录面板跟随讲课进度，点击句子跳转，全文搜索并在进度条上标出结果。
- **笔记、书签、“没听懂”标记与讨论区**：和原播放器用同一份数据，与 Echo360 保持同步；带时间点的内容会标在进度条上。
- **音频处理**（默认关闭）：音量均衡（适合老师没戴麦克风的录像）、人声增强、单声道。
- **静音和空白画面检测**：在进度条上标出长时间静音（课间休息、小组讨论），以及画面全黑或空白且没人说话的时段；有“跳过”按钮，也可以开启自动跳过。录像结尾是长时间空白时，会提示课程内容已结束。
- **幻灯片章节**：自动找出屏幕画面里的每次换页。“幻灯片”标签页列出每一页的缩略图和老师讲的内容；进度条上标出章节分隔，悬停时显示预览。`Shift+←` / `Shift+→` 切到上一页 / 下一页。
- **跟着幻灯片读**：把老师的幻灯片 PDF 拖到播放器上，“幻灯片”标签页就变成一个 PDF 阅读器，随着讲课自动翻到正在讲的那页（识别屏幕上的文字，在 PDF 里找到对应的页）。你随时可以自己翻，点一下就能回到老师讲到的地方。PDF 只保存在你的设备上。
- **私人标签**：给笔记和书签加标签（“考试”“作业”或自己建的），按标签筛选，进度条上按颜色显示。标签只存在你的设备上。
- **放大和平移**：用滚轮或触控板放大屏幕画面、摄像机画面或幻灯片 PDF，拖动移动，双击复原。
- **A-B 循环**：反复播放一段（一个推导、一句话）。
- **观看进度**：进度条上显示看过的部分；课程页上每节课有一个小进度条，同时显示本设备看过的部分和 Echo360 记录的上次停下位置。
- **悬浮窗**：把整个播放器弹成一个置顶的小窗口，一边看一边写代码或做题。
- **中文或英文界面**：默认跟随浏览器语言（浏览器设为任何中文时显示简体中文）；可以在 ⋮ →“语言”里切换。
- **导出和备份**：把笔记、书签和标签导出为 Markdown（带回到那一刻的链接；有幻灯片 PDF 时附带页面图片），可以导出一节课或整门课。只存在浏览器里的数据可以备份和恢复。
- **不被打断**：Echo360 的视频访问权限在后台自动续期，长时间观看不用刷新页面。
- **续播**：从上次停下的位置继续，换设备也有效（使用 Echo360 服务器记录的位置）。
- **如实上报观看记录**：和原播放器一样向 Echo360 报告观看进度，数据来自你实际播放的部分。
- **随时可以切回**：右上角“原播放器”按钮从当前位置切回 Echo360 播放器；出现任何问题时会自动退回原播放器，并为原播放器启用 CPU 补丁。

## 隐私

- 脚本只在 Echo360 课程页面运行。除了 Echo360 本身，只向一个地方发送数据：下面说明的匿名使用数据，可以关闭。
- 设置、续播位置和分析缓存只保存在你的浏览器里（localStorage 和 IndexedDB）。
- hls.js 在播放器即将启动时从 jsDelivr 以固定版本加载，SHA-256 哈希匹配才运行（否则使用原播放器）；pdf.js 和 Tesseract.js（文字识别）也以固定版本加载，只在录像添加了幻灯片 PDF 时加载。文字识别在你的浏览器里进行。
- 标签、观看进度、幻灯片文件和备份只存在你的设备上。导出和备份文件里从不包含视频本身或视频地址。
- 不会替你发布任何内容：对 Echo360 的写入（笔记、帖子、标记）只在你点击时发生；老师或同学能看到的内容，发送前会明确提示。
- 不提供下载功能。

### 匿名使用数据

默认开启，在**设置（⋮）→ 使用数据**里可以关闭，关闭后立即停止发送。用途是发现只在部分电脑上出现的问题，并决定先改进什么。

- **发送什么：**
  - 电脑和浏览器，每天最多一次：脚本、浏览器、系统和脚本管理器的版本，界面语言，桌面还是触屏，屏幕尺寸和缩放，CPU 核心数，处理器类型（x86 或 ARM、32 或 64 位）、系统版本和安卓设备型号（浏览器提供时），内存和显卡，WebGPU 报告的显卡厂商和架构，WebGPU、WebCodecs、浏览器内置 AI 和 CPU 压力读数是否可用，视频是否由硬件解码（720p 和 1080p），当时是否在充电，浏览器计时器的精度，网络类型和估计带宽；
  - 每次观看一条汇总：
    - 启动：脚本怎样启动（在原播放器启动前拦下、接管已经启动的原播放器，或把页面留给原播放器），脚本运行时页面的加载状态，多久后显示出播放器，接管后拦下了原播放器的多少次观看上报；
    - 观看体验：是否随页面一起打开，多久后控件可用、出现第一帧，拖动进度后多久出画面（中位数、P90），缓冲（次数、时间占比），各清晰度的时间占比和切换次数，估计带宽，两路画面的同步偏差（中位数、最大值）；
    - 响应和负担：点击和按键多久得到响应（中位数、P90、超过 200 ms 的次数），主线程长任务，掉帧，内存，播放时间（标签页可见时）里各 CPU 压力等级的占比（后台分析进行中和没有后台分析分开统计），整个播放期间是一直插电、一直用电池还是两者都有；
    - 后台分析：每小时录像下载的数据量，每小时播放的视频数据量，多少结果来自缓存，章节和 PDF 跟读多久后可用，各步骤耗时（每个关键帧、每分钟音频、文字识别和 PDF 绘制每百万像素：中位数、P90、次数）；
    - 这台设备有多快：分析中两段固定的计算（无论录像内容如何，工作量都一样）每百万像素或每百万音频采样的耗时（P10、P50、P90，批数，以及每批结束时视频是否在播放、倍速、CPU 压力和电源）。这些数字来自分析本来就要做的工作，没有为测量额外运行任何东西；
    - 稳定性：因出错被关闭的功能，本脚本未捕获的错误数，按类型分的请求失败（被拒绝、服务器错误、超时、无响应），按名称分的视频流错误，视频访问续期的成功和失败次数，Echo360 页面代码的版本（其脚本文件名）；
    - 使用习惯：打开和播放的时长，看了录像的多少，各倍速的时间占比和最常用的布局，跳过的无声和空屏秒数，各功能的使用次数，快捷键和点击的比例，你改过哪些默认设置（只有设置**名称**），界面语言和主题，切回原播放器之前看了多久；
    - 分析效果：屏幕画面怎样识别出来，每小时章节数，PDF 跟读未识别时间占比，手动纠正次数，自动布局切换被撤销的次数；
    - 使用数据本身：发送失败的次数，因排队太多而没有发送的错误条数；
  - 切回原播放器的次数和原因，以及脚本运行时页面的加载状态；
  - 错误：功能名、错误类型，以及去掉了网址、邮箱、引号内文字、ID 和数字的错误消息。

  时间和速度都四舍五入到两位有效数字，只发送汇总值（中位数、百分位数、次数），不发送逐条数据。
- **从不发送：**姓名、账号、学号、邮箱；看了哪些课程或录像、它们的标题或地址；你写的任何内容（笔记、标签、讨论）；字幕或幻灯片内容；你的 IP 地址。
- **存在哪里：**本项目自己的 Cloudflare Worker 和 D1 数据库（代码在 [`telemetry-worker/`](telemetry-worker/)）。Worker 只保存上面列出的字段，其余一律丢弃。它保存 Cloudflare 根据请求得出的国家、地区和网络运营商，不保存 IP 地址；IP 地址只用作一分钟限流计数器的键。不记录请求日志。数据长期保存，不自动删除。
- **怎样认出你：**首次使用时脚本生成一个随机密钥，由脚本管理器保存，从不显示或导出。你的数据以这个密钥的 SHA-256 哈希为 ID 保存。查看和删除需要密钥本身，所以别人即使知道你的 ID，也无法查看或删除你的数据。
- **你的数据：****设置 → 使用数据**里有“查看我的数据”（表格，可下载 JSON）、“删除我的全部数据”（先确认，确认后立即从服务器删除）和“重置 ID”（生成新密钥；重置后旧 ID 无法再使用，所以会先问你要不要删除旧数据）。
- Greasy Fork 对此的标注是 `@antifeature tracking`。

## 已知限制

- 直播课程，以及需要先确认版权声明的录像，会使用原播放器。
- 投票、幻灯片、附件和口述影像只在原播放器里有（播放器里有按钮可以切过去）。
- 学校登录在播放中过期时会提示刷新，刷新后从当前位置继续（Echo360 的视频访问权限本身会在后台自动续期）。
- 没有 PDF 时的幻灯片章节：每段录像自己学习多大的画面变化算换页；屏幕很少整体变化的录像（摄像头拍白板）章节可能较少。如果在错误的画面里找幻灯片，可以在“幻灯片”标签页选择正确的画面。
- 跟读幻灯片 PDF 时按 PDF 的语言识别屏幕文字（英文、中文、日文、韩文、俄文、希腊文、阿拉伯文、希伯来文、泰文、印地文；其他按英文）。英文以外的语言首次需要下载文字识别数据（0.6–2.7 MB）。
- 没有转录的录像靠音频检测静音，离麦克风较远的小声说话可能会被当成静音。除非你开启自动跳过，是否跳过始终由你决定。

## 开发

```sh
npm install        # 开发工具（ESLint、用于检查的 TypeScript、happy-dom）
npm run build      # src/*.js -> dist/lite-player-for-echo360.user.js（可读，不压缩）
npm test           # 单元测试和整页测试
npm run ci         # 代码检查、类型检查、测试、dist/ 与源码一致（GitHub Actions 运行的就是这些）
```

只修改 `src/`（`dist/` 是生成的）。代码结构说明：[ARCHITECTURE.md](ARCHITECTURE.md)（英文）。

`src/` 下的源文件是普通脚本，按文件名顺序拼接。代码和注释用英文，界面文字集中在 `src/01-i18n.js`，所有调节参数（带单位和依据）集中在 `src/02-tuning.js`。
